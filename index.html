🎀 Sobre nuestro proyecto 🎀

¿Qué es el Nail Art?

El Nail Art es el arte de decorar y embellecer las uñas mediante diferentes colores, dibujos, diseños y técnicas creativas que permiten expresar el estilo de cada persona.

Objetivo general

Implementar un centro de Nail Art personalizado con herramientas digitales para mejorar la experiencia del cliente y facilitar la elección de diseños de uñas.

¿En qué consiste nuestra innovación?

Nuestra innovación consiste en utilizar una página web para mostrar diferentes diseños de uñas, permitir que los clientes conozcan nuestros servicios y facilitar las solicitudes de reservas de manera sencilla.

Importancia del proyecto

Este proyecto permite combinar la creatividad, la belleza y la tecnología. También ayuda a que los clientes puedan observar diferentes diseños y elegir el que más les guste de acuerdo con sus preferencias.
